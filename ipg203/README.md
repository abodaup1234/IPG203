# نظام إدارة مركز صيانة الأجهزة المنزلية

مشروع Console بلغة C# يطبق مفاهيم OOP المطلوبة في الوظيفة.

## التشغيل
1. ثبّت .NET 8 SDK.
2. افتح الطرفية داخل مجلد المشروع.
3. نفّذ: `dotnet run`

## محتويات المشروع
- `Models/IRepairable.cs`: الواجهة المشتركة.
- `Models/Appliance.cs`: الفئة المجردة والخصائص المشتركة والأحداث والإحصائيات.
- `Models/Refrigerator.cs`: فئة الثلاجة.
- `Models/WashingMachine.cs`: فئة الغسالة.
- `Models/AirConditioner.cs`: فئة المكيف.
- `Services/ValidationHelper.cs`: التحقق من البيانات.
- `Services/RepairCenter.cs`: إدارة قائمة الأجهزة والبحث والتنبيهات.
- `Program.cs`: القائمة الرئيسية وتجربة الوظائف.

الأسعار الإضافية داخل الفئات الفرعية افتراضية لغرض المثال، ويمكن تعديلها حسب المطلوب.
